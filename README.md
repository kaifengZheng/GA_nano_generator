# Genetic algorithm for reconstruction of nanoparticles by known descriptors
## The purpose of this code
* Decoding the structural and morphological information is crucial work after measuring samples containing nanoparticles. This information paves the way to discover the nano-world. However, experimental tools, such as spectroscopies, always provide very limited information stored in several variables, i.e. descriptors, and constructing the whole landscape of the sample or representative nanoparticles is an impossible mission. This tool provides a way of reconstructing nanoparticles using several known descriptors. The merit of using a genetic algorithm is that the outcome provides a distribution of nanoparticles instead of a single solution. People can also evaluate other computable properties of those generated nanoparticles.
